# Security practice

This is a deliberately simple lab. Do not put real credentials in Git.

Recommended next exercises:
- GitHub Actions OIDC to AWS instead of long-lived AWS keys.
- AWS Secrets Manager / External Secrets for runtime secrets.
- Trivy for container and IaC scanning.
- Least-privilege IAM roles.
- NetworkPolicy in Kubernetes.
- Non-root containers (already enabled in the Docker image).
